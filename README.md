# Developer Portfolio

A personal portfolio website built with Next.js, Tailwind CSS, and shadcn/ui. Content is loaded from `data/portfolio.json`.

## Features

- Hero section with intro and skills
- Experience timeline
- Projects with live and code links
- Education
- Contact section
- Resume download

## Tech Stack

- [Next.js (App Router)](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)

## Getting Started

### Prerequisites

- Node.js ≥ 18.x
- npm

### 1. Clone the repo

```bash
git clone https://github.com/AravindAnkamalla/devspace.git
```

### 2. Install and run

```bash
npm install
npm run dev
```

Edit `data/portfolio.json` to update the site content.
